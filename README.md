### Descripción

BookArt-Website es un proyecto de sitio web de comercio electrónico para "BookArt Encuadernaciones", 
una empresa especializada en encuadernación y venta de libros personalizados. 

El proyecto contiene código fuente completo para una plataforma web que permite a los usuarios navegar por un catálogo de productos, 
realizar compras, gestionar pedidos y contactar con la empresa. Incluye funcionalidades de carrito de compras, sistema de autenticación de usuarios, 
panel administrativo y sistema de mensajería integrado con PHPMailer.

### Puntos Principales de Funcionalidad
- Catálogo de productos con visualización de portadas
- Carrito de compras funcional con gestión de pedidos
- Sistema de inicio de sesión y autenticación de usuarios
- Panel administrativo para gestión de pedidos
- Sección "Mis Pedidos" para que usuarios vean su historial
- Formulario de contacto con sistema de correo electrónico
- Opciones de personalización de productos
- Extensiones del catálogo para diferentes categorías

### Pila Tecnológica
Backend: PHP (76.3%)
Frontend: CSS (14.5%), JavaScript (9.2%)
Bibliotecas: PHPMailer (para gestión de correos electrónicos)
Base de datos: No especificada en el repositorio
